Import Processor Transactions

Import PeachPOS transaction history from a supported non-Square payment processor using a CSV or Excel file.

Before Uploading

Choose the Processor Company that produced this file.

The uploaded file must contain a Merchant ID / Account ID column. Every imported row must contain the same identifier, and it must exactly match the identifier saved in Processor Company Setup.

Peach Suite Pro will block the import if the processor account cannot be verified.

Using Square?

Square transactions use Peach Suite Pro's native Square integration and cannot be imported through Processor Transactions.

Only active non-Square processors in this Provider Workspace are available.
